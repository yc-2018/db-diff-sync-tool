# 2026-07-31

## 完成：数据库同步比对工具（Windows 桌面应用）

从零构建了双库比对工具，技术栈 **Python 3.13 + pywebview（原生窗口+网页UI）**。

**项目结构**（均在项目根目录）：
- `app.py` — pywebview 入口 + JS API 桥（连接管理、比对调度、配置持久化到 `~/.dbsync_tool/connections.json`，密码 Base64 混淆）
- `dbcore.py` — 比对核心：Oracle（优先，oracledb 纯 Python 模式免客户端）/ MySQL / SQLite 三种方言的元数据读取、结构差异 DDL、数据差异 DML 生成
- `web/` — index.html / style.css / app.js（左右双栏、连接表单、数据库下拉+新建连接、同步数据表/同步数据两模式、只读SQL+复制）
- `tests/selftest.py` — SQLite 双库端到端自测（结构/数据修复SQL执行后两侧一致）
- `启动.bat`（pythonw 无窗口启动）、`初始化环境.bat`（首次建venv）、`README.md`

**核心设计**：
- 两侧必须同类型数据库（连接时校验）
- 结构比对覆盖列(类型/可空/默认值)+主键；SQLite 改列走重建表方案
- 数据比对按主键；无主键仅识别多/少行并告警；单表上限20万行、单向SQL上限5000条
- 应用只生成SQL供复制，绝不执行（用户明确要求）

**已验证**：selftest 全过（两轮：只执行左侧SQL / 只执行右侧SQL 均收敛一致）；Api 层全流程模拟调用通过；GUI 冒烟启动通过。

**踩坑（已修复）**：`.bat` 文件被 Write 工具存成 UTF-8(无BOM)，cmd 按 GBK 解析导致中文行变乱码命令（'t' 不是内部或外部命令）。教训：**写给 Windows cmd 的 .bat 必须纯 ASCII**（错误或提示用英文），已重写 启动.bat / 初始化环境.bat 并实测拉起 pythonw 进程成功。

**环境坑（复用价值）**：
- 沙箱内 pip 需加 `--no-cache-dir`，否则报 SAFE_DELETE_FAIL
- venv python 路径：`.venv/Scripts/python.exe`
- 后台 Bash 任务用 TaskOutput 回收输出
